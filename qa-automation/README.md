# Автоматизація тестування Tasteorama

## Про проєкт

У цьому проєкті я використовую Playwright та JavaScript для автоматизації тестування сайту Tasteorama.

Поки що налаштувала Playwright і додала перші два тести для перевірки головної сторінки.

## Що вже зроблено

- Встановила та налаштувала Playwright.
- Налаштувала `baseURL` у файлі `playwright.config.js`, щоб не писати повну адресу сайту в кожному тесті.
- Перевірила, що Tasteorama запускається локально через Docker.
- Додала два прості тести.
- Запустила тести в Chromium. Обидва пройшли успішно.

## Як запустити тести

Спочатку потрібно запустити Tasteorama через Docker і перевірити, що сайт відкривається за адресою:

`http://localhost:5173`

Після цього перейти в папку `qa-automation`.

Якщо залежності ще не встановлені:

```bash
npm install
```

Для встановлення браузерів Playwright:

```bash
npx playwright install
```

Запуск тестів у Chromium:

```bash
npx playwright test --project=chromium
```

Щоб подивитися результати тестування у звіті:

```bash
npx playwright show-report
```

## Які тести додала

**1. has title**

Відкриває головну сторінку та перевіряє, що в заголовку є назва Tasteorama.

**2. search button is visible**

Відкриває головну сторінку та перевіряє, що кнопка Search відображається.
